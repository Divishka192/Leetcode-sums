Find Sum of Each Row

Problem Statement:
Given a matrix, find the sum of elements in each row.

Example:

Input:
2 3
1 2 3
4 5 6

Output:
6
15

Explanation:

Row 1 = 1 + 2 + 3 = 6
Row 2 = 4 + 5 + 6 = 15

Java Code:

import java.util.*;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int r = sc.nextInt();
        int c = sc.nextInt();

        int[][] a = new int[r][c];

        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                a[i][j] = sc.nextInt();
            }
        }

        for (int i = 0; i < r; i++) {
            int sum = 0;

            for (int j = 0; j < c; j++) {
                sum += a[i][j];
            }

            System.out.println(sum);
        }
    }
}
