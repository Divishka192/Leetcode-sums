Count Positive and Negative Numbers
Problem Statement

Given an array of N integers, count how many numbers are positive and how many are negative.

Ignore 0.

Example

Input:

6
-2 5 -7 8 0 3

Output:

Positive: 3
Negative: 2
Code
import java.util.*;

class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int positive = 0;
        int negative = 0;

        for (int i = 0; i < n; i++) {

            if (arr[i] > 0) {
                positive++;
            }
            else if (arr[i] < 0) {
                negative++;
            }
        }

        System.out.println("Positive: " + positive);
        System.out.println("Negative: " + negative);
    }
}
Explanation

Array:

[-2, 5, -7, 8, 0, 3]

We check each element:

-2 < 0 → negative = 1
 5 > 0 → positive = 1
-7 < 0 → negative = 2
 8 > 0 → positive = 2
 0     → ignore
 3 > 0 → positive = 3
