Contains Duplicate 
Question: Given an integer array, return true if any value appears at least twice.

Example:
- Input: nums = [1,2,3,1]
- Output: true



class Solution {
    public boolean containsDuplicate(int[] nums) {
        for(int i = 0; i < nums.length; i++) {
            for(int j = i + 1; j < nums.length; j++) {
                if(nums[i] == nums[j]) {
                    return true;
                }
            }
        }
        return false;
    }
