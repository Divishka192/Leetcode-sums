345. Reverse Vowels of a String
Question

Given a string, reverse only the vowels in the string.

Example:

Input:  "hello"
Output: "holle"
Easy Code
class Solution {
    public String reverseVowels(String s) {
        char[] a = s.toCharArray();

        int i = 0;
        int j = a.length - 1;

        while (i < j) {

            while (i < j && !isVowel(a[i]))
                i++;

            while (i < j && !isVowel(a[j]))
                j--;

            char temp = a[i];
            a[i] = a[j];
            a[j] = temp;

            i++;
            j--;
        }

        return new String(a);
    }

    public boolean isVowel(char ch) {
        return ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u'
            || ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U';
    }
}
Explanation

We use two pointers.

hello
↑   ↑
i   j
i starts from the left.
j starts from the right.
Move i until we find a vowel.
Move j until we find a vowel.
Swap those two vowels.
Move both pointers.

For "hello":

h e l l o
  ↑     ↑
  e     o

Swap e and o:

h o l l e

Answer:

"holle"
