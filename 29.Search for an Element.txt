Search for an Element
Problem Statement

Given an array and a number X, check whether X is present in the array.

Print Yes if present, otherwise print No.

Example

Input:

5
10 20 30 40 50
30

Output:

Yes
Code
import java.util.*;

class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int x = sc.nextInt();

        boolean found = false;

        for (int i = 0; i < n; i++) {

            if (arr[i] == x) {
                found = true;
                break;
            }
        }

        if (found) {
            System.out.println("Yes");
        } else {
            System.out.println("No");
        }
    }
}
Explanation

For:

arr = [10, 20, 30, 40, 50]
x = 30

We check:

10 == 30 → No
20 == 30 → No
30 == 30 → Yes

Then:

break;
