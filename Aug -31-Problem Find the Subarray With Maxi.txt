Problem: Find the Subarray With Maximum Sum
Question

Given an integer array nums, find the contiguous subarray that has the largest sum and return that sum.

Example
Input:
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

Output:
6
Explanation

The subarray with the maximum sum is:

[4, -1, 2, 1]

Its sum is:

4 + (-1) + 2 + 1 = 6


Java Code
class Solution {
    public int maxSubArray(int[] nums) {

        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {

            currentSum = Math.max(nums[i], currentSum + nums[i]);

            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
🔍 Explanation

We use two variables:

int currentSum = nums[0];
int maxSum = nums[0];
currentSum

Stores the maximum sum of a subarray ending at the current position.

maxSum

Stores the maximum sum found so far.

Main logic
currentSum = Math.max(nums[i], currentSum + nums[i]);

We have two choices:

Choice 1: Start a new subarray from the current number.

nums[i]

Choice 2: Add the current number to the previous subarray.

currentSum + nums[i]

We choose whichever is bigger.

Example
[-2, 1, -3, 4, -1, 2, 1]

Starting:

currentSum = -2
maxSum = -2

For 1:

max(1, -2 + 1)
max(1, -1)
= 1

So:

currentSum = 1
maxSum = 1

For -3:

max(-3, 1 + (-3))
max(-3, -2)
= -2

For 4:

max(4, -2 + 4)
max(4, 2)
= 4

Then:

-1 → currentSum = 3
2  → currentSum = 5
1  → currentSum = 6

So:

maxSum = 6


This problem teaches Kadane's Algorithm.

Remember the simple idea:

At every element, decide whether to continue the previous subarray or start a new one.

Complexity
Time:  O(n)
Space: O(1)
