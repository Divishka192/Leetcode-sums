Question: Cyclically Shift Rows and Columns

You are given:

An integer n
A 2D integer array grid of size n × n
An integer array rowShift of length n
An integer array colShift of length n
Meaning
rowShift[i] = number of positions to cyclically left shift row i.
colShift[j] = number of positions to cyclically upward shift column j.

First, shift every row according to rowShift.

Then, shift every column according to colShift.

Return the final grid.

Important

For a left shift by k:

newColumn = (oldColumn - k + n) % n

For an upward shift by k:

newRow = (oldRow - k + n) % n

JAVA CODE
class Solution {
    public int[][] cyclicShift(int n, int[][] grid, int[] rowShift, int[] colShift) {

        int[][] a = new int[n][n];

        // Step 1: Shift rows to the left
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {

                int col = (j - rowShift[i] + n) % n;

                a[i][col] = grid[i][j];
            }
        }

        // Step 2: Shift columns upward
        int[][] result = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {

                int row = (i - colShift[j] + n) % n;

                result[row][j] = a[i][j];
            }
        }

        return result;
    }
}
