# 27. Remove Element

**Date:** August 9

## 🧩 Problem

Given an integer array `nums` and an integer `val`, remove all occurrences of `val` in-place. The order of elements may be changed.

Return the number of elements in `nums` which are not equal to `val` (denoted as `k`).

### Requirements:

* First `k` elements should contain values ≠ `val`
* Remaining elements don’t matter
* Return `k`

---

## 🧪 Example 1

**Input:**
nums = [3,2,2,3], val = 3

**Output:**
k = 2
nums = [2,2,*,*]

---

## 🧪 Example 2

**Input:**
nums = [0,1,2,2,3,0,4,2], val = 2

**Output:**
k = 5
nums = [0,1,4,0,3,*,*,_]

---

## 💡 Approach

* Use a variable `k` to track position of valid elements
* Traverse array
* If element ≠ val → place it at index `k`
* Increment `k`

---

## 💻 Java Solution

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int k = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != val) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
}
```

---

## ⏱ Complexity

* Time: O(n)
* Space: O(1)

---

## 🧠 Key Idea

👉 Keep only elements that are **not equal to `val`** by shifting them forward.
