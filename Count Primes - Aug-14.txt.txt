# 204. Count Primes - Aug-14.txt

Problem:
Count the number of prime numbers less than n.

Example 1:

Input: n = 10

Prime numbers less than 10:
2, 3, 5, 7

Output: 4

Example 2:

Input: n = 0

Output: 0


Java Code:

class Solution {

    public int countPrimes(int n) {

        int count = 0;

        for (int i = 2; i < n; i++) {

            if (isPrime(i)) {
                count++;
            }
        }

        return count;
    }

    public boolean isPrime(int num) {

        for (int i = 2; i < num; i++) {

            if (num % i == 0) {
                return false;
            }
        }

        return true;
    }
}


Explanation:

1. Start from 2 because 0 and 1 are not prime numbers.

2. Check every number less than n.

3. Call the isPrime() function.

4. If the number is prime, increase the count.

5. Return the final count.


Dry Run:

Input: n = 10

2 -> Prime -> count = 1

3 -> Prime -> count = 2

4 -> Not Prime

5 -> Prime -> count = 3

6 -> Not Prime

7 -> Prime -> count = 4

8 -> Not Prime

9 -> Not Prime

Output: 4


Time Complexity: O(n²)

Space Complexity: O(1)
