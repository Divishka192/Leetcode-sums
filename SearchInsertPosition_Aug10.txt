Problem: Search Insert Position

Given a sorted array of distinct integers and a target value,
return the index if the target is found.
If not, return the index where it would be inserted.

Approach:
We use Binary Search because time complexity must be O(log n).
since it is asking for sorted array and also for time complexity o(logn)

Steps:
1. Initialize left = 0 and right = n - 1
2. Find mid = (left + right) / 2
3. If nums[mid] == target → return mid
4. If target < nums[mid] → search left half
5. Else → search right half
6. If not found, return left (insert position)

--------------------------------------------------

Code (Java):

class solution{
public program(int[] nums,int target){
int low=0;
int high=nums.lenght-1;
while(low<=high){
int mid=(low+high)/2;
if(nums[mid]==target){
return mid;
}
else if(nums[mid]<target){
low= mid+1;
}
else{
high= mid-1;
}}
return low;
}}
--------------------------------------------------

Example:

Input: nums = [1,3,5,6], target = 2
Output: 1

Explanation:
2 is not present, but should be inserted at index 1.
