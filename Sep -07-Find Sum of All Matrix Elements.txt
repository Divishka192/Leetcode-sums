2. Find Sum of All Matrix Elements

Problem Statement:
Given a matrix, find the sum of all its elements.

Example:

Input:
2 2
1 2
3 4

Output:
10

Logic:
1 + 2 + 3 + 4 = 10

Java Code:

import java.util.*;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int r = sc.nextInt();
        int c = sc.nextInt();

        int[][] a = new int[r][c];
        int sum = 0;

        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                a[i][j] = sc.nextInt();
                sum += a[i][j];
            }
        }

        System.out.println(sum);
    }
}
