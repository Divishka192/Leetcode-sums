BEST SEAT - CODECHEF

QUESTION:
You are given an array of N distinct integers, where Ai represents the number of the ith available seat in a cinema hall.

The center position is defined as the average of the smallest and largest values in A.

Find the available seat closest to the center position.
If two seats are equally close, choose the smaller seat number.

EXAMPLE:
Input:
5
10 20 30 40 50

Output:
30


EXPLANATION:
Step 1: Find the smallest and largest seat numbers.

Smallest = 10
Largest = 50

Step 2: Find the center position.

center = (10 + 50) / 2.0
center = 30

Step 3: Find the distance of every seat from the center.

10 -> |10 - 30| = 20
20 -> |20 - 30| = 10
30 -> |30 - 30| = 0
40 -> |40 - 30| = 10
50 -> |50 - 30| = 20

The smallest distance is 0, so the answer is 30.


LOGIC:
1. Read N and the array.
2. Find minimum value.
3. Find maximum value.
4. Calculate center = (min + max) / 2.0.
5. Start with the first seat as the answer.
6. Calculate its distance from the center.
7. Check every other seat.
8. If its distance is smaller, update the answer.
9. If the distance is equal, choose the smaller seat number.
10. Print the answer.


JAVA CODE:

import java.util.*;

class Codechef {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] a = new int[n];

        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        int min = a[0];
        int max = a[0];

        for (int i = 1; i < n; i++) {
            if (a[i] < min)
                min = a[i];

            if (a[i] > max)
                max = a[i];
        }

        double c = (min + max) / 2.0;

        int ans = a[0];
        double b = Math.abs(a[0] - c);

        for (int i = 1; i < n; i++) {
            double d = Math.abs(a[i] - c);

            if (d < b) {
                b = d;
                ans = a[i];
            }
            else if (d == b && a[i] < ans) {
                ans = a[i];
            }
        }

        System.out.print(ans);
    }
}


IMPORTANT:
- min = smallest seat number
- max = largest seat number
- c = center position
- b = best (smallest) distance found so far
- d = current seat's distance from center
- ans = seat number closest to the center
- Math.abs() gives the absolute/positive distance.
- Use 2.0 instead of 2 so that the center can be a decimal value.

TIME COMPLEXITY:
O(N)

SPACE COMPLEXITY:
O(N), because we store the array.
